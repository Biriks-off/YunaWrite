## Features

-1.**Modify Python plug-ins**

  The original Python plug-in will have problems on Windows😭
  We revised this question.Added some hints.So you can run Python programs more ('safely')on YunaWrite

-2.**soft**
  Among some soft keyboards and mobile phone keyboards,there are no shortcut keys.So we added the ('soft') instruction.In this way, (＇soft keyboard') users can also experience it easily.

-3.**opin**
  When we open the executable program file,It is often necessary to call the terminal of the operating system.So we designed the ('opin') instruction.In this way, you can run the executable program files in the ('YunaWrite environment').I believe it will be more interesting🤩

*('.sh')/('.bat')/('.command')*

-4.**ft**
   We already have plug-ins cbat and cpp(GCC).But when we write this code, we may think about indentation.So we added ('ft').This still depends on the ('clang') compiler.
   *You may need this command to modify the indentation in the code.This will make the code look better！(I hope so😂)*
   *By clang-format*

-5.**crb**
    YunaWrite is *desperate* now😂
